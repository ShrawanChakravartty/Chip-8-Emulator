# Chip - 8 Emulator
Learning and implementing Chip - 8 emulator in c

# Steps to lauch the emulator
Step 1 :- use "make" to compile the files       

Step 2 :- use "./chip8 PROGRAM_PATH" to run the chip8 with the specific rom     

NOTE - Replace the PROGRAM_PATH with your games relative path and to escape press ESC on the keyboard
